# Bảng màu Flamee — Landing Page

Palette landing page lấy từ nhận diện hiện có của ứng dụng Flamee. Dùng nhất quán trên toàn trang.

| Vai trò | Màu | Mã |
|---|---|---|
| Nền chính | Kem sáng | `#EEECEA` |
| Nền khu vực / thẻ | Trắng ấm | `#FFFCF8` |
| Chữ chính | Nâu đậm | `#302924` |
| Chữ phụ | Nâu xám | `#70655D` |
| Màu thương hiệu | Coral | `#FF7158` |
| Màu nhấn phụ | Cam đào | `#FCB76D` |
| Viền nhẹ | Be xám | `#E6DDD3` |

## Gradient thương hiệu

`#FCB76D → #FF7158`

## Cách dùng

- Dùng nền kem/trắng ấm làm nền chính, chữ nâu đậm cho nội dung.
- Dành coral cho CTA và điểm nhấn thương hiệu; dùng cam đào làm màu hỗ trợ.
- Giữ chữ phụ và viền ở vai trò phân cấp nhẹ, không dùng làm màu nhấn chính.
